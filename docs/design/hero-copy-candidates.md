# 首屏答句候選（打字機文案）

依 `style-language-v1.md` §5.2（每字 100ms、只跑一次、打完不刪不重打）與 §6（不用標語體、
不堆形容詞、句號結尾、標題講主張說明講依據）。答句一律 26 字以內，句子要能一個字一個字讀
過去都成立。示範文件名全為假名，不得換成真實客戶文件。字數指實際要打的字元數，含標點、
數字與中西文之間的空格；秒數為字數乘以 0.1 秒。

## 候選一　條款型

| 欄位 | 內容 |
|---|---|
| 訪客問題（小字靜態） | 這份 2023 年的採購契約，驗收付款怎麼寫？ |
| 答句（打字機） | 驗收後 30 天內付款，逾期加計利息。 |
| 引註標記 | 來源：採購契約範例_2023.pdf 第 12 頁 |
| 字數 ／ 秒數 | 19 字 ／ 1.9 秒 |
| 簡報依據 | S2 優勢 6「每句都指得到、原文哪一份哪一頁」；S4 與 S5 的 IKS「回應附上來源檢視與索引」 |
| 為什麼有效 | 打出來的是條款內容本身，不是「我找到了 3 筆結果」。訪客看到的是產品在做事，不是產品在自我介紹。逐字讀到「30 天內付款」時句子就已經成立，後半只是補條件。 |

## 候選二　誠實型

| 欄位 | 內容 |
|---|---|
| 訪客問題（小字靜態） | 逾期交貨要罰多少錢？ |
| 答句（打字機） | 合約只寫逾期通知，沒有寫罰款金額。 |
| 引註標記 | 來源：採購契約範例_2023.pdf 第 14 頁 |
| 字數 ／ 秒數 | 17 字 ／ 1.7 秒 |
| 簡報依據 | S2 優勢 1「有依據才回答、查不到就說查不到」；S1 成果能力「低 AI 幻覺」 |
| 為什麼有效 | 唯一能讓紅波浪批註有戲的一句：波浪畫在「罰款金額」四個字下面，訪客不用看說明就懂那條線的意思。風險是首屏第一印象是一句否定句。 |

## 候選三　跨格式型

| 欄位 | 內容 |
|---|---|
| 訪客問題（小字靜態） | 這張手寫驗收單上的日期是幾號？ |
| 答句（打字機） | 手寫驗收單上寫的是 3 月 14 日。 |
| 引註標記 | 來源：驗收單範例_手寫掃描.pdf 第 3 頁 |
| 字數 ／ 秒數 | 19 字 ／ 1.9 秒 |
| 簡報依據 | S1 資料流第一段「PDF、Word、Excel、掃描件、手寫、圖片」；S2 優勢 8「掃描件、手寫、圖表、照片都讀得懂」 |
| 為什麼有效 | 一句話就回答了「手寫的到底吃不吃得下」，這是 KIP 最容易被懷疑的一點。缺點是它證明的是輸入端，不是可追溯本身。 |

## 建議與版面組成

採用**候選一**當首屏。它同時具備三件事：答句是文件裡的原話、句尾帶得出頁碼、句子在打到一半時
就已讀得通。候選二不丟掉，移到立場段當紅波浪的示範，那裡本來就是講原則的地方，一句否定句放在
第五段比放在首屏安全。候選三移到「會換詞」那一段，它與五個輪替文件型態講的是同一件事。
首屏可讀文字合計約 57 字元，在 §1.3 的 93 字元預算內。

| 元素 | 規格 | 時間 |
|---|---|---|
| 訪客問題 | 24 ／ 400、次墨 `#64645e`，行動 18 ／ 400。靜態不打字，置於答句上方 24px | 隨進場揭露淡入 400ms |
| 答句 | 96 ／ 300、墨 `#282825`、字距 -0.02em，行動 46.8 ／ 300。欄寬 0.74 倍容器 | DOM ready 後 75ms 起打，每字 100ms，1.9 秒打完 |
| 游標 | 0.06em 寬實心方塊，貼最後一字右側 | 打完常駐，0.6s 一循環硬切閃爍 |
| 引註標記 | 14px 等寬（中文落回無襯線）、次墨。貼答句左下，`top: calc(100% - 0.25rem); left: 1.25rem` | 最後一字打完後延遲 300ms，透明度 0 到 1 共 300ms 線性，不位移 |
| 紅波浪（選用） | 珊瑚 `#eb5b55`，只在採用候選二時出現，畫在無依據的那幾個字下方，旁邊 14px 同色小字 | 遮罩擦除 300ms，由左至右 |
| 降級 | `prefers-reduced-motion` 開啟時直接顯示完整答句與引註，游標不閃 | 無 |

時間軸：0ms 問句淡入，75ms 開始打字，1975ms 打完並留下游標，2275ms 引註淡入，全程 2.3 秒。
