# SynaiQ 企業官網改版｜線框 v2

灰階線框，結構定案用。**不含配色與字體決策**。三個寬度是同一套流體版面的三個切片，
不是兩套固定版型。每張線框右側 320px 為標註欄，內含：區塊名、媒介、來源、動態、收合狀態、
該斷點的重排規則；折線以虛線與「FOLD」標籤標示。

參考站實測見 [`reference-notes.md`](reference-notes.md)；KIP 內容出處代號 `S1`–`S6` 見
[`kip-deck-extract.md`](kip-deck-extract.md)。

## 1. 斷點系統（提案）

| 項目 | 值 |
|---|---|
| 斷點 | 640（單欄↔雙欄）／900（抽屜↔完整導覽、表格↔卡片）／1280（進入最大容器） |
| 容器寬 | `min(100% - 2×gutter, 1240px)`；gutter＝`clamp(20px, 4vw, 100px)` |
| 三個切片的實際容器 | 390→350／768→704／1440→1240 |
| 元件內部 | 卡片與表格改用 **container query**，同一元件放進不同欄寬都能自己決定要不要換行 |
| 觸控 | 所有可點目標 ≥ 44px；hover-only 的揭露一律另附 tap 行為；輪播一律可用手勢 |
| `prefers-reduced-motion` | 進場與計數改為直接顯示終值；自動輪播停止（保留手動）；視差關閉；展開列保留 120ms 淡入（理解需要） |

**流體字級（`clamp()`，括號內為三個切片的實測值）**

| 角色 | 公式 | 390 ／ 768 ／ 1440 |
|---|---|---|
| Hero 大標 | `clamp(1.875rem, 5.6vw, 5rem)` | 30–34 ／ 48 ／ 72–80 |
| 區塊標題 | `clamp(1.5rem, 3vw, 2.75rem)` | 25–26 ／ 32 ／ 44 |
| 內文 | `clamp(0.9375rem, 0.6vw + 0.8rem, 1.0625rem)` | 15 ／ 16 ／ 17 |
| 表格內文 | 14–15 ／ 15 ／ 16 |  |
| 眉標 | 11–12px，字距 .20–.24em，**每頁至多 2 次** |  |

## 2. 動態語彙（7 種，全站只用這 7 種）

| 代號 | 行為 | 用在哪 | reduced-motion |
|---|---|---|---|
| `hero-rise` | 眉標→大標→CTA→支持句，位移 20px＋淡入，間隔 60ms，700ms | 每頁首屏，只播一次 | 直接顯示 |
| `slide-cross` | 全幅影像交叉淡入＋8% 位移，自動 6 秒，hover／focus 暫停 | 僅首頁與 /cases 的首屏 | 停自動，只留手勢 |
| `scroll-reveal` | 進入視窗 15% 時位移 20px＋淡入，600ms，只播一次 | 所有非首屏區塊 | 直接顯示 |
| `count-up` | 數字 1.2s ease-out，只播一次 | 數字帶、案例數字 | 直接顯示終值 |
| `row-expand` | 表格列／摺疊高度展開 260ms＋內容 120ms 淡入 | 所有可展開表格與 FAQ | 保留 120ms 淡入 |
| `image-parallax` | 全幅影像在其捲動範圍內位移 ±4% | 僅全幅照片區塊 | 關閉；觸控裝置一律關閉 |
| `pin-wipe` | 畫面釘在導覽列下，下一段由下往上覆蓋；畫面本身不縮放、不位移 | 首頁架構圖與 `/kip` 平台架構；每頁至多 1 次 | `<900px` 與 reduced-motion 改一般靜態段落，四層說明全顯示 |

## 3. 收合模式（5 種）

| 代號 | 樣態 | 用在哪 |
|---|---|---|
| A 分頁 | 同形狀的平行內容，一次顯示一組 | KIP 三段資料流 |
| B 可展開列 | 表格列點開露出第二行說明 | 八項優勢、五型號比較、案例表、媒體報導 |
| C 摺疊清單 | 標題列點開露出區塊 | 行動版頁尾、團隊學經歷 |
| D 覆蓋層 | 全螢幕放大，可縮放／左右切換 | 產品截圖、案例照片 |
| E 更多按鈕 | 「展開全部 N 則」一次開啟 | 八項優勢、媒體報導 |
