## 後續完成：新增語言自動化

同日依使用者要求，改為掃描各語言 JSON 資料夾自動註冊。`npm run i18n:add -- ja` 建立語言設定與十份空白翻譯；完成翻譯後 `npm run i18n:sync` 一次生成登錄表、載入器、語言模組、示意圖、sitemap 與靜態 SEO 語系標籤。白名單、瀏覽器匹配和發布快取規則自動支援新語言。`npm run dev:design` 會先自動同步。

本次沒有加入日文或法文的正式譯稿；新增語言驗證使用隔離目錄中的測試資料，不會出現在使用者預覽。

最新驗證：網站 209 項（204 通過、5 項既有條件略過）、發布 23 項通過、瀏覽器 99 項通過。瀏覽器矩陣現為所有語言 × 八個公開頁面 × 四種寬度，加三組流程。整合測試另外確認只增加第四語言 JSON 就能生成及載入、瀏覽器區域匹配、新示意圖與 sitemap、過期產物／漏譯／重複別名拒絕，以及新增範本拒絕覆寫與路徑越界。

證據：`out/i18n-migration/automation-design.log`、`automation-deploy.log`、`acceptance-2026-10-28T07-33-52-644Z/report.json`。第一次發布路徑模擬發現動態示意圖前綴未被封裝改寫，已修正並重跑全部 99 項通過。以下保留原三語遷移階段紀錄；首屏速度未在新增自動登錄後重測。

## 已完成

- 繁中、英文、德文共用版型；30 份分類 JSON 為翻譯唯一人工維護來源。
- 每次開頁只載入選定語言的完整 JS 模組，另有小型三語啟動／錯誤提示。共用快取、載入狀態、失敗重試與切換語言均已驗證。
- 語言優先順序為網址 lang → 瀏覽器偏好 → 繁中；無效或空白的明確 lang 回到繁中。手動選擇與站內連結保留 lang，語言切換保留案例及錨點。
- 生成檔一致性、鍵值／型別／陣列／替換參數完整性列入測試與發布前檢查。原有 CI 執行 test:design，因而會阻擋過期生成檔。
- 德文正文、導覽、動畫、操作與無障礙標籤、圖說及頁面摘要已補齊；KIP 德文 SVG 從共用翻譯生成。真實截圖與照片保持原圖。
- SEO 語系資料、24 個 sitemap 網址、發布白名單、發布目錄資源路徑及語言模組快取規則已更新。

## 首屏量測

同一部電腦與 Chrome、冷快取、80ms 延遲、下載 2MB/s、上傳 1MB/s；前後都停用外部字型請求。各語言各跑五次，以主標題加入 DOM 的時間中位數比較，並非 LCP、所有圖片完成或正式站速度。

| 首頁 | 改造前 | 提早載入後 | 差異 |
|---|---:|---:|---:|
| 繁中 | 941.7ms | 839.6ms | 約 -10.8% |
| 英文 | 854.0ms | 778.6ms | 約 -8.8% |

與語言相關的傳輸量（包含載入工具與啟動訊息）由 97,400 bytes 降為繁中 46,203 bytes、英文 49,415 bytes。本機沒有壓縮；正式 CDN 壓縮、網路與快取可能改變結果。

第一輪改造曾量得繁中 948.7ms、英文 892.0ms，沒有速度收益；把 bootstrap 模組提早在 head 執行後才得到上表結果。保留 `benchmark-before.json`、`benchmark-after.json`、`benchmark-early.json`，不只保留最佳一輪。德文沒有改造前版本可比較。
