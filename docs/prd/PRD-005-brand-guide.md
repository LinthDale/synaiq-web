# PRD-005：網站品牌與素材維護

| 版本 | 狀態 | Owner | ADO Feature | 最後更新 |
|---|---|---|---|---|
| v0.4 | 現行品牌基線；完整手冊驗收另計 | Dale | [#1300](https://dev.azure.com/synaiq/SynaiqDev/_workitems/edit/1300) | 2026-09-09 |

## 1. 目標

維護已採用的網站品牌、字型、Logo 與素材。設計來源是 [live-prototype](../design/live-prototype/README.md)，不再等待舊色票、字型或三案選擇。

## 2. 範圍

只涵蓋網站，不擴張至完整 CIS、簡報、社群、印刷或展場物料。整理現行基線不代表完整資產清冊、對比度矩陣及圖示手冊已驗收完成。

| 項目 | 現行來源 |
|---|---|
| 配色、字級、間距 | `live-prototype/` 實際載入的 CSS，保留紙色／墨色／橄欖綠及明暗區段 |
| 展示字 | Newsreader＋Noto Serif TC，不再保留字型比較稿 |
| 共用 Logo | `live-prototype/brand.js`；淺底用 `assets/synaiq-logo-ink.svg`，深底用 `/brand/synaiq-logo-light.svg` |
| 產品畫面 | 核准品牌配色示意圖、範例資料與模擬動畫；不換回未去識別化的後台截圖 |
| 圖像 | 原色 Wally 圖、CEO 素描、小貓、背景線稿與撕紙；來源說明與生成工具保留 |
| 語言／Logo 操作方式 | [統一管理指南](../design/live-prototype/localization-and-brand-guide.md)，目前沒有上傳 CMS |
| Astro token | `src/styles/tokens.css` 是 Phase A 中性基礎，不是目前網站品牌色票 |

## 3. 原 FR 對應

保留編號以區分現有資源與未完成驗收；本次不更新 ADO 狀態。

| FR | 維護原則 |
|---|---|
| FR-501 色票 | 從核准版 CSS 維護，不用已移除的候選 token 草稿覆蓋；完整允許組合／對比度表另需量測 |
| FR-502 字型 | 展示字已選定，保留流體字級與雙語排版；字型打包及 subset 變更需另驗證授權、載入與效能 |
| FR-503 Logo | 由 `brand.js` 統一引用，依指南更換明暗底資產並同步產品示意畫面；禁止拉伸、擅改色或加背景 |
| FR-504 圖像 | 保留核准素材與原色產品圖，依來源說明處理裁切、去識別化、尺寸與格式，不用舊灰階線框素材 |
| FR-505 清冊 | 預覽公開範圍由 `share-preview.mjs` 的 `PUBLIC_FILES` 明列；它不是整個 `public/` 的完整品牌清冊 |
| FR-506 維護 | [設計入口](../design/README.md) 與語言／Logo 指南；改素材需重新生成衍生圖、跑測試並單獨發布 |

## 4. 品質界線

沿用 [PRD Guideline](../guidelines/PRD-Guideline-Web.md) §4。Logo 明暗底、對比度、圖片體積與全裝置驗收依實際變更檢查，不因文件整理而視為完成。

## 5. 保留與安全

保留現有原圖、公開衍生檔、生成腳本、測試及來源說明；未公開的 CIS／去識別化參考圖繼續保持 Git 忽略。本機憑證 `.env.hostinger.local` 不讀入網站、不進 Git、不包入部署檔。部署及還原包保留。

## 6. 驗證方式

更換 Logo 後依指南同步四張中英示意畫面，執行 `npm run test:design`，人工檢查兩頁、兩語系、明暗底與窄幅。本次清理不新增完整品牌清冊及 AA 對比度矩陣。

## 7. 非風格擇案的後續事項

移除已過時的配色、字型與 Logo 缺檔擇案問題。未提供的商標規範、素材授權／委託限制及新增媒材範圍，不因已有網站素材就推定已獲授權。
